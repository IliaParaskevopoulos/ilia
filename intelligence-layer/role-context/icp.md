# ICP

_Updated: 2026-10-20_

**Method:** ICP framework (HubSpot / Gartner) + Jobs-to-be-Done.
Per segment: profile → buyer vs user → job → pains → triggers → channels → objections → disqualifiers → value metric.
B2C segments use demographics; B2B uses firmographics.

---

## ICP 1 — Pets
| | |
|---|---|
| **Profile** | Dog owner (also outdoor cats), 25–55, DACH/EU, suburban/rural |
| **Buyer = user** | Owner |
| **Job** | "Find my dog fast when it runs off." |
| **Pains** | Escapes, hunting breeds, fear of theft, AirTag useless off-network |
| **Triggers** | New puppy · near-loss incident · move to rural area · holiday trip |
| **Channels** | Amazon, pet retail, dog forums, vets, Instagram |
| **Objections** | Subscription cost · battery life · collar weight for small dogs |
| **Disqualify** | Indoor-only pets · dogs < 4 kg |
| **Value metric** | Minutes to find pet |

## ICP 2 — Seniors
| | |
|---|---|
| **Profile** | Adult child 40–65 caring for parent 75+, often early dementia |
| **Buyer ≠ user** | Buyer: adult child · User: senior |
| **Job** | "Know mum is safe without taking her independence." |
| **Pains** | Wandering, falls, no smartphone skills, guilt, distance |
| **Triggers** | Wandering episode · fall · diagnosis · parent lives alone |
| **Channels** | Google search, Amazon, pharmacies, care services, Facebook groups |
| **Objections** | Senior refuses to wear it · too complex · privacy · vs Hausnotruf |
| **Disqualify** | Full-time residential care with own system |
| **Value metric** | Peace of mind · SOS response time |

## ICP 3 — Fleet
| | |
|---|---|
| **Profile** | SMB, 3–50 vehicles: trades, delivery, construction, rental, plant hire |
| **Buyer ≠ user** | Buyer: owner / ops manager · User: dispatcher |
| **Job** | "See where my vehicles and equipment are, cut cost and theft." |
| **Pains** | Theft, fuel cost, manual logbooks, time disputes, no dispatch view |
| **Triggers** | Vehicle/equipment theft · tax logbook requirement · fleet growth · insurer demand |
| **Channels** | Google search, Amazon Business, trade associations, insurers, resellers |
| **Objections** | Driver privacy (GDPR, works council) · "enterprise tools too expensive" · install effort |
| **Disqualify** | > 200 vehicles needing deep ERP/telematics integration |
| **Value metric** | € saved per vehicle per month |
