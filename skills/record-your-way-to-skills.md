# Record Your Way to Skills

**Do the job once on camera, get the skill.**  ·  Reads: the whole layer

## Prompt

I'm going to give you a recording or transcript of me doing a task once (screen recording, call, narrated walkthrough).

1. Watch/read it fully. Extract the steps I took, the decisions I made, and the criteria behind each decision.
2. Separate what is **judgment** (needs my context) from what is **mechanical**.
3. Map each judgment to the intelligence-layer file it should read from (e.g. "prioritized this account because it matches the ICP" → `icp.md`). If the knowledge isn't in the layer yet, tell me what to add and where.
4. Write the result as a reusable skill file in `skills/<task-name>.md` with: purpose, inputs, files it reads, step-by-step instructions, output format, and a quality checklist.
5. Ask me up to 3 questions about anything ambiguous in the recording before finalizing.
